# 旧DSP拓扑深度、真实PREG时序及共用聚类门槛

2026-10-23最新用户决定：不独立配置最小簇规模，不把所有DSP作为组合节点。

- 逻辑深度和结构聚类沿用旧DSP尾部拓扑判定，部分DSP仍为端点；不使用真实PREG重新划分结构深度的端点。
- STA、时序驱动QP和关键路径估计继续使用真实PREG：1截断、0组合。两类计算分别保存节点层数，避免结构统计覆盖公共时序字段；这是同一DSP的两种用途判定，不代表独立配置路径门槛与簇规模。
- 原forward-level累计95%规则算出T；长路径条件为L>T，最小簇规模仍为真实cell数>=T。没有独立BoundaryPaperMinCells，传入该参数明确报错。
- 本例T需由网表计算，不在配置中写18。原BoundaryPaperPathLengthThreshold显式覆盖能力保留，但正常配置省略，覆盖时两处一起变化。
- 初始ClusterPlacer与SLR/CR层级聚类均使用旧拓扑深度。STA优化器、SLL一阶公式、DSP坐标修复、区域容量、裁剪、扩散和阶段预算保持不变。
- SllRegionPolicy=preserve；release-single仍为已实现、当前不启用的实验策略。
- 本次只构建并运行无布局检查，不启动AMF布局或Vivado。恢复旧聚类规则不保证恢复旧布局，因为时序权重仍按真实PREG修正。

替代方案的历史代码/测试保留在bec17b95原副本；“所有DSP组合”候选已撤回，不用于后续实验。
