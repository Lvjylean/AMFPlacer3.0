## 结论

**范围补充（2026-09-25）：本报告原始检查范围仅为 AMFplacer3.0。用户另有 `non_dataflow_case` 项目，已经实现资源感知 partition、多 SLR / CR 区域规划、跨 SLR 代理代价和软 Pblock 导出，与第二步高度重合。后续应优先复用该前端并开发 AMF 接口及器件支持，不能将下述 AMF 仓库缺口解释为用户尚无相关实现。详见 [跨项目接入评估](partition-floorplan-amf-integration-assessment.md)。**

**第二步部分完成：AMF 2.0 的通用初始聚类、资源统计、递归图划分、加权连接模型、模拟退火预布局和基础时序分析可复用，且初始聚类与预布局已经在完整实验中执行；计划书要求的多芯粒初始分配及相关优化尚未实现。**

当前映射关系是 `PlacementUnit → cluster → 二维时钟区域网格/初始坐标`，没有显式的 `cell/cluster → die/SLR` 分配、芯粒连接拓扑及 SLL 容量/延迟模型。不能把时钟区域或一般空间分区直接视作一个芯粒，也不能以 AMF 全流程通过证明多芯粒方案完成。

## 建议下一步及阶段验收

建议先补齐 **“芯粒拓扑与资源模型 + 可检查的初始分配结果”**，再逐项扩展优化器。以下是建议的实施拆分，不是已经完成的工作或计划书的额外强制条款。

1. 选定一个真实多芯粒器件与输入设计，导出 Site/ClockRegion 到 die/SLR 的映射、每芯粒资源供给与固定对象归属；接口预留相邻芯粒连接容量和延迟来源。
2. 将现有簇统计扩展为资源需求向量，明确宏的可放置芯粒和边界约束，输出 `cluster → die` 及初始锚点。先做到分配可行、可核对，再比较优化效果。
3. 按计划书补充 min-cut ILP，并加入跨芯粒通信和关键路径代价；PaToH 可保留为初始解/对照，不能把它直接标记成 ILP 已实现。
4. 复用 SA、拓扑图和轻量 STA，增加跨芯粒延迟、权重反馈、芯粒内/芯粒间聚类及资源驱动的粒度调整。记录各目标项，防止只减少跨界网络却使某芯粒拥塞。
5. 保存初始分配、每芯粒各类资源利用率、跨界连接需求、关键路径跨界情况和阶段耗时；用真实器件完成后端验证，并与未加入多芯粒优化的基线比较。原 faceDetect 单芯粒实验保留为回归。

第二步可关闭的核心条件是：多芯粒模型真实、初始分配满足所声明的资源与宏约束、通信/关键路径代价实际参与优化、报告能解释分配结果，并有真实多芯粒实验支撑。完整增量控制器属于下一阶段，不作为第二步必须先完成的前提。
