# SLL 数量模型、QP 接入与跨 SLR 闭环验收

第一批的数量模型、解析梯度、QP 接入及真实设计 GP 闭环已实现并验证。关闭功能能精确复现普通 Pro。开启后，数量目标能影响真实跨 SLR 移动，且能按阶段解释数量变化；**当前参数并未优于普通 Pro 的最终离散需求，不能据此替换默认基线。**

本次验收界面是完整 GP 前缀及其内部宏合法化，包含中间增量配对打包。最终 CLB 打包、Vivado placement/routing、WNS/TNS 和实际 SLL 占用 U 未纳入此次验证。空间需求和热点优化留待后续。

## 验收结果

| 步骤 | 结果 | 证据 |
| --- | --- | --- |
| 1. 基线与输入口径 | 通过 | GETRF/U250、10 ns、8 线程，普通 Pro，`ProPrimitiveTiming=false`；全部非 SLL 配置和输入哈希一致；阶段预算一致；原基线 3,645 个受保护文件未改变 |
| 2. 数量模型 | 通过 | 15 种非空四 SLR 分布整数计数正确；同侧多 sink 不重复计数；真实设计独立 Python 计数与 C++ 追踪完全一致 |
| 3. 梯度与并行归约 | 通过 | 有限差分最大绝对误差 `1.15249e-11`；串行/8 线程梯度最大误差 `5.77316e-15`；ASan/UBSan 通过 |
| 4. QP 接入 | 通过 | 关闭后 856,998 个 cell 的 X/Y 和 PU 编号全部精确相同；合成跨界算例 S 从 1 到 0；实际 80 次 QP 的候选与写回后统计一致，合成目标无增加 |
| 5. 数量闭环 | 通过 GP 范围验收 | 真实 S 发生改变；使用同区域策略对照；记录 QP、扩散、显式裁侧、宏合法化和阶段间变化；同时比较相同实际迭代前缀 |

独立内核共 86 项检查通过。当前真实设计的 80 次候选均直接接受，没有触发回溯或回滚，不能把本次运行说成已覆盖所有失败分支。

## 冻结设置与结果


最终二进制来自标准构建 `build-20261013-105501-020605-e7f6ac93`。构建快照内 3,437 个源码文件与实现提交后的源码逐文件一致；二进制 SHA-256 为 `705733bfb2f335628356f2967e228ac2835fee3dceaef0db495597f03d204e7d`。

数量组参数固定为 `lambda=100`、`tau=30`、`gamma=0.25`、`curvature=0.002`、单次 Y 位移上限 10；不做扇出截断。保留原 Pro 的 U250 坐标/距离系数、SRL 共享、弱牵引等设置。

`release-single` 仅释放可移动、未打包普通 LUT/FF 的启发式区域偏好，宏、LUTRAM、固定/锁定对象不释放。所选偏好项的 X/HPIO 与 Y/SLR 指引一同释放，因此必须用相同释放策略作对照。它本身不是新的默认配置。

| 组别 | 最终 S | S_optimized | 最终 WASLL | GP 轮数 | AMF HPWL |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原二进制普通 Pro | 11,085 | 11,083 | — | 37 | 3,928,446.572 |
| 新二进制，数量关闭，保留偏好 | 11,085 | 11,083 | 4,340.707 | 37 | 3,928,446.572 |
| 释放单体偏好，数量关闭 | 14,372 | 14,370 | 4,422.860 | 37 | 3,512,651.354 |
| 相同释放策略，数量目标开启 | 12,396 | 12,394 | 3,350.278 | 40 | 3,418,626.888 |

最终数量组相对同策略对照减少 **1,976，13.75%**；相对普通 Pro 增加 **1,311，11.83%**。释放偏好本身将 S 从 11,085 增加至 14,372，所以不能把数量组与释放对照之间的改善说成优于普通 Pro。

阶段配置始终一致，依次为 `SLR 2 / HPIO 10 / SLR 2 / HPIO 6 / SLR 2 / HPIO 6 / HPIO 6 / HPIO 15`。最后阶段沿用原来的非严格停止条件：原版和两个关闭组实际运行 3 轮，数量组运行 6 轮，均以 `macro_fixed` 结束。

为隔离实际轮数差异，再比较共同的前 37 轮：

| 相同 GP 前缀 | S |
| --- | ---: |
| 普通 Pro | 11,085 |
| 释放偏好、数量关闭 | 14,372 |
| 同策略、数量开启 | 11,771 |

此时数量组相对同策略对照下降 **18.10%**，但仍比普通 Pro 高 **6.19%**。其后额外三轮将 S 从 11,771 增至 12,396，回增 **625**。这说明“代理目标有效下降”和“最终整数数量优于普通 Pro”是两个不同验收结论。

## 各阶段造成了什么变化

下表是每组完整运行中，相邻阶段快照的 ΔS 累加；负数表示该阶段减少跨界需求。它是迭代过程的收支，**不是消除的唯一网络数**。数量组运行 40 轮，两个对照运行 37 轮，因此不能直接把各列累计量当作相同工作量的收益比较。

| 阶段 | 保留偏好、数量关 | 释放偏好、数量关 | 数量组 |
| --- | ---: | ---: | ---: |
| Timing 步 | −47 | −1,660 | −601 |
| QP1 + QP2 | −180,346 | −225,178 | **−135,124** |
| 扩散区间，含内部区域投影 | +183,480 | +233,551 | **+139,978** |
| 后续显式裁侧 | +184 | +51 | +292 |
| 宏合法化 | +940 | +734 | +968 |
| 迭代/阶段间处理 | +4 | +4 | +13 |
| 合计，最终 S − 初始 S | +4,215 | +7,502 | +5,526 |

三组初始 S 均为 6,870，初始布局指纹一致。当前样本中，主要回增来自扩散区间；阶段间处理的净贡献很小，不能把大幅回增归因于配对打包。

数量组 QP 步累计观察到 **78,356 次 PU anchor 跨 SLR 移动事件**，证明新代价确实进入了位置更新。其扩散区间包含 32,069 次 X 投影和 22,656 次 Y 投影；后续显式裁侧另有 187 次 X 投影、121 次 Y 投影。纯 X 投影不会直接改变这个仅依赖 Y 的 S 模型，但会影响后续布局过程。

实现中候选检查发生在写回前。接受时只提交一次坐标并保留正确的 `lastAnchor` 历史；拒绝时不改 PU 和锚点历史。这样不会让一次试探写回干扰下一轮伪网模型。

## 数量统计的边界

模型读取真实接缝 `239.5 / 479.5 / 719.5`。最终逐接缝结果为：

| 组别 | 接缝 0 | 接缝 1 | 接缝 2 | 合计 |
| --- | ---: | ---: | ---: | ---: |
| 普通 Pro / 新版关闭 | 9,639 | 1,446 | 0 | 11,085 |
| 释放偏好对照 | 12,994 | 1,378 | 0 | 14,372 |
| 数量组 | 10,424 | 1,972 | 0 | 12,396 |

统计覆盖 AMF 原始设计中的 1,178,774 个普通网络、3,852,283 个 pin；排除 1 个 AMF global-marked 网络和 2 个常量网络。所有阶段的缺失映射和越界网络数均为 0。

124 个网络没有显式 driver，184 个网络只有一个 pin，类别存在重叠；优化过滤合计 302 个网络。S 使用所有观察到的普通网络 pin 跨度；S_optimized 与 WASLL 使用同一个优化网络集合。对缺少显式 driver cell 的外部输入网络，S 只反映已知 pin 的跨度，不补造外部端点位置。

以上均为布局阶段的拓扑估计。没有统计路由后的物理 SLL 去重占用 U，也没有测量本组 Vivado WNS/TNS。多组运行有并发和诊断开销，墙钟仅作为复现记录，不能用来得出性能优劣结论。
