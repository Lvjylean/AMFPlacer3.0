## 当前默认行为与验证范围

- 常规合法化匹配使用 `legacy`，候选选择保留 `cached_topk`；实验配置中的其他后端需显式选择。缓存选择的同成本排序可能影响结果，不承诺所有设计与旧实现逐位一致。
- `full-run` 默认采用 `repair`；需要严格导入时使用 `--strict-import`。历史实验配置与冻结构建保留，未把所有配置统一改成 R10 参数。
- 提交前：115 项现有 Python/Tcl 轻量回归全部通过；71 个待提交 Python 文件与 19 个 JSON 文件通过语法检查。
- 本次是源码快照上传，没有重新编译 C++ 或执行完整布局布线，也未切换 `builds/current`。R10 等已有实验仅证明其各自冻结构建与配置的结果，不能代替整个当前工作区的全流程验收。
- DCP、构建产物、运行日志、许可证和大型缓存不入库；生成的 `color.tcl` 与空的 `experiments/registry.lock` 留在服务器，不纳入版本。
