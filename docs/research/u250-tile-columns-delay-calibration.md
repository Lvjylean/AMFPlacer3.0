# U250 tile 列坐标下的三段延迟重新拟合

**实现状态更新（2026-09-29）：** 用户随后明确选择 U250 统一使用近段原值、中远段新值，不增加按连接类型或训练范围切换模型的规则。现已接入并通过编译及原生数值验证，见 [U250 新延迟系数接入](u250-delay-coefficients-runtime.md)。下文保留拟合完成时的评估与候选阶段结论；其中“尚未加载”的状态已由这次实现更新，拟合误差和覆盖范围记录不变。

2026-09-29。本轮使用用户暂定接受的补列规则 `tile-columns-subsites-v3`：按U250自身tile列与左右子位置生成X，每个独立特殊COLUMN补1个单位列。坐标规则在本轮拟合中固定，不把这些宽度当作待拟合参数。

**结论：近段保留原参数；中、远段得到新的局部候选。中段平均误差改善但P95略有恶化。候选尚未加载进placer，也不适合直接全局替换。**

## 数据、公式和隔离方式

复用已经采集的R08、R06 routed DCP的连接延迟，分别4188、4060条，共8248条观测、6119个不同driver/sink连接对。实测标签为Vivado 2024.2的 `NET_DELAY.SLOW_MAX`，由ps转ns；没有混入cell delay。物理site和实测延迟不变，只用新坐标重新计算dx/dy和分段。本轮没有新placement、route或DCP查询，也没有下载DCP。

- R08：`getrf-u250-full-20260928-160231-470820`。
- R06：`getrf-u250-full-20260927-125004-730657`。
- 新物理模型：`data/devices/u250-tile-columns-v3/model/physical_structure.tsv`。
- 原样本目录：`experiments/preflight/20260929-u250-piecewise-delay-01/`。
- 本轮目录：`experiments/preflight/20260929-u250-tile-columns-delay-01/`。
- 本地轻量证据：`experiments/evidence/20260929-u250-tile-columns-delay/`。

延迟公式保持冻结C++实现的形式：

```text
dx = abs(Xsource - Xsink)
dy = abs(Ysource - Ysink)
r² = dx² + dy²

near:   r² < 9
middle: 9 <= r² < 36
far:    r² >= 36

Dlocal = max(0.05,
    [c0 + c1*(2dx)^0.3 + c2*dy^0.3
        + c3*(2dx)^0.5 + c4*dy^0.5] / 1000) ns
Dtotal = Dlocal + existing_boundary_penalty
```

分段在X乘2之前判断。c数组单位为ps；0.05ns下限、1.5ns/SLR及0.5ns/HPIO边界项不变，SA与共享y2xRatio不参与这次系数拟合。

按driver的SHA-256桶隔离：桶2–4拟合、桶1选择ridge、桶0保留验证；选定ridge后使用桶1–4重新拟合，最终训练3335条，R08保留853条。R06排除1709个与最终训练重叠的driver，剩2351条验证。每个布局每个driver只取一个sink。R06以前已用于分析，因此本轮是独立布局和driver隔离验证，**不是新的盲测集，更不是独立设计验证**。

候选alpha仅由R08调参桶选择，未根据R06调整系数或改选alpha。最终是否保留候选依据R08/R06误差和条件配对bootstrap审计。普通指标与原抽样权重指标同时记录。

R08的原中段有368条转为近段，原远段有318条转为中段、11条转为近段。说明本次实际改变了距离与分段，而非沿用旧分组重新写入系数。

原抽样按旧RPM距离、方向、SLR、类型和fanout分层，因此本轮重分段后仍保留每条样本原来的population/sample_count权重，不把它冒充新坐标重新均衡抽样。筛除训练driver后的加权指标是保留子集的条件统计，不能当作全设计连接的严格无偏误差。

两轮均只含LUT/FF普通数据连接，fanout=1–8，同SLR且端点不跨HPIO带；覆盖SLR0/1/2，没有SLR3。包括跨普通CR连接：R08为951条，R06为780条。没有cross-SLR/IO带样本，也没有硬资源端点或高fanout样本；端点检查不能排除实际布线绕行或经过局部硬块附近。

R08新分段近/中/远分别有17/45/683种训练dx/dy组合；矩阵秩均为5。最终训练的加权有效样本量约431/379/268。现有数据足以完成当前局部模型的一轮拟合，因此没有为了凑新分段配额再次查询DCP。

## 相同实测连接上的两次拟合比较

使用完全相同的R06保留2351条连接和延迟标签，同时对比四种坐标/参数组合。最后两行才是上次与本次拟合后模型的比较；均采用近段原参数＋对应中远段候选。

本次拟合后的MAE比上次拟合后低约2.27%，RMSE低约1.05%，属于小幅改善。2000次driver配对bootstrap的差值区间：MAE[−0.003463,−0.001654]ns，RMSE[−0.002537,−0.000913]ns。这些区间以既定系数与复用的验证样本为条件，不包括跨设计或重新训练的不确定性。

## 稳定性、范围与形状

R06按driver进行1000次配对bootstrap，拟合候选减原参数的RMSE变化95%区间：

- 近段：[+0.001966,+0.003447] ns，明确恶化，保留原参数。
- 中段：[−0.009339,−0.001744] ns，平均误差改善，但P95从0.22911升到0.23754ns。
- 远段：[−0.221997,−0.180405] ns，当前局部样本中改善明显。

200次训练driver重采样后，中段各单独系数仍不稳定，不能逐项解释为物理常数。验证预测区间宽度的中位数/P95分别为：近0.0192/0.0236ns、中0.0564/0.1048ns、远0.0872/0.1473ns。此处近段指被否决的拟合候选。

最终训练范围：

- 近：dx 0–2.5，dy 0–2；
- 中：dx 0–5.5，dy 0–5；
- 远：dx 0–54，dy 0–168。

矩形范围不表示全部组合都覆盖，JSON另存dx/dy凸包。R06近、中验证均在各自训练凸包内；远段954条中951条在凸包内，3条在外，其中2条超出上述矩形。远段凸包内MAE为0.34141→0.14497ns。3条外推样本不足以证明外推可靠，凸包内也不等于每种物理环境均被覆盖。

近段验证有23条实测小于0.05ns，原生下限会限制这类连接的可拟合程度。

推荐组合（近旧＋中新＋远新）全器件诊断网格没有负预测或触发0.05下限，仍存在靠近坐标轴的小范围非单调性。r=3处跳变范围[+0.01878,+0.06208]ns；r=6处[−0.02997,+0.04479]ns，最大向下跳变约30ps。分段模型未强制连续或全局单调，网格诊断不能替代实测外推验证。

## 范围外诊断与使用决定

已有关键路径样本仅作适用性诊断，不参与训练或选alpha。它们有选择偏差，不能推广为全设计误差。在新坐标下，对范围外远段直接套用新候选：

|R08|136|4.70726|5.71001|

单位ns。新候选会进一步低估这些跨界、高扇出或其他不符合训练范围的连接，因此**不能将三段数组直接覆盖全局默认值**。范围外保留原模型仅是未校准回退，并不代表其已准确。本轮输出的是有坐标版本绑定、有适用连接范围的候选参数；尚未实现运行时按适用范围选择模型。

## 原生复算与追溯

从冻结构建 `build-20260928-002048-349585-d534237b` 的 `PlacementTimingOptimizer.h` 直接提取 `getDelayByModel_conservative`，编译独立C++校验程序，分别代入原参数和推荐参数。物理边界接口在这项局部公式校验中返回0，与拟合样本没有端点跨界的条件一致。

8248个样本距离加30个r=3/6附近测试点，原参数与Python最大差为2.4733e-7ns，推荐参数为1.5189e-7ns。测试采用原生float分段与最终float返回，证据含冻结header、提取函数、独立源文件和二进制哈希。

LUT/FF样本没有PCIE特殊pin偏移；复算使用最终routed cell-site锚点。它不是历史优化迭代中cellLoc的快照，不能声称恢复了所有placer内部时序预测。该报告评估连接净延迟，不评估路径cell/clock/约束组合，更不代表最终placement或WNS改善。

`fit.json` 保存每段系数、样本划分、MAE/RMSE/bias/P90/P95/相关性及加权指标；`fit-audit.json` 保存fanout与端点类型分组、bootstrap和范围外诊断；`coordinate-review.json` 保存相同连接上的四种组合、同/跨CR、SLR分组、距离覆盖和原生验证。

程序记录耗时：拟合约0.31秒，初次统计审计约1.00秒，最终坐标/支持范围/C++复算审计约1.62秒；不包含文件传输、前期脚本编写及报告整理。记录在manifest，不能作为placer布局计时。

旧样本、旧拟合报告和当前C++默认数组保留。本轮新增独立候选和报告，原始DCP、样本及验证二进制仍留服务器。
