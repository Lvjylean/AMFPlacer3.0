# 2.0优化加速版本

发布日期：2026-11-01。目标 GitHub 分支：`codex/sll-edge-compact-snapshot-20261024`。
本版在提速版1.0 `d04315a3` 上发布已完成等价验收的生产提交 `1672cf86c4b029d2550f9d1a465ce12914b8321c`。发布整理仅增加文档；算法、脚本、配置和测试与该生产提交一致。“2.0”是优化版本标签，项目名称仍为 AMFplacer3.0。

## 本次实现

1. 串行密度网格重建采用已有 exclusive 插入路径，避免锁和重复集合查找。其他并发插入入口保留锁；PU及宏内cell顺序、容量first-fit、fallback、重置/set分配顺序和整数占用转换均保留。
2. global/CLB辅助网格复用同次共享资源遍历已求出的坐标与bin编号，未启用历史实验网格后端。
3. 边界报告的只读跨界计数使用既有线程进行整数归约，小集合保留串行。端点排序、图状态副作用、关键路径选择、完整报告内容和输出顺序保留。

继承提速版1.0及之前的 L 分段修正、增量编译、SLL规划/约束与可视化实现。没有减少刷新、报告或计算轮数，也没有改变模型公式、浮点运算顺序、容量策略及候选决策。

## 同配置验收及时间

GETRF/U250、10 ns、eda072、AMF 12线程、普通Pro且`ProPrimitiveTiming=false`、SLL数量/动态tau/规划/容量/时序/约束优化全开、`visualization=false`、`CrossDieSpreadMaxBins=0`、`SllRegionPolicy=preserve`、`AllowSplit=false`。与基准有效配置仅输出目录不同，输入哈希一致。复用已综合优化的输入，只运行AMF布局及SLL计划导出，没有执行综合或Vivado后端。

## 一致性及小型验证

- AMF退出0，仅amf阶段；无可视化帧、新DCP。GP均37轮、QP均92次；grid/audit/STA/SLL刷新调用数一致。
- 最终Tcl、FinalLUTFF、resources、cascades逐字一致；PUInfoFinal仅对无序`PULegalization:`行规范排序后解压内容一致，不能宣称其原始压缩字节完全相同。
- SLL计划逐字一致；371条选定非耗时算法日志一致；完整`amf_boundaries.tsv`及`amf_critical_paths.tsv`逐字一致。
- 144组网格状态差分覆盖5/2.5/2网格、宏偏移和full/bypass；这是小型fixture，不代替完整GETRF验收。边界空/小/30081边、1/12线程整数结果一致；动态开关、跨die扩散写回、SLL联合QP及六组slack回归通过。
- 计划9446 nets / 9467 crossings；SLR01=8974、SLR12=493。1062个tile对，203个>80%、152个>90%、77个满额、0超容量；最热列COLUMN310/349为1080/1440=75%。这些均为planned结果，不是Vivado实际布线资源验收。

本轮没有新WNS、可布线性或端到端编译加速结论。`SllRegionPolicy=release-single`仍是已实现、当前暂不启用的实验策略；不改变preserve基准。端点排序优化、更深入的网格成员复用/批处理、扩散临时容器及去重、SLL刷新稳定拓扑索引复用尚未实施，不纳入本版。
