# 多器件布局查看器入口

当前发布位于 [`tools/placement_viewer`](../../tools/placement_viewer/README.md)。支持 U250 与 VHK158、先选器件再选历史运行、DCP 元数据分类、新旧轨迹目录、端口复用身份校验、预览真实进度和模块追踪。

完整安装、SSH 配置、启动方式、数据格式和测试说明见上述 README。配置只影响查看器；不更改 placer 配置或算法。DCP 只有器件/路径信息时不能播放 AMF 迭代，需要同一运行已有的坐标轨迹。

本次发布不包含实验 DCP、轨迹、缓存和私人运行索引。VHK158 placer 的资源模型适配与可视化显示支持是不同部分；本工具可以打开已完成实验的 VHK158 输出，不把此发布称为完整的 VHK158 placer 源码发布。
