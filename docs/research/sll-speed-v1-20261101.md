# 提速版1.0

本版整理已验证的 SLL 运行时优化，保留新 L 表达、增量编译与 SLL 规划功能。源码基于已验证的 `e9a21f594caab335c39fca80646a7f164781b30f`，生产优化实现为 `daa5b47f0990eaee6470b4e284d3ff698f33a2cb`。

## 本版优化

- 详细日志未打开时，跳过纯日志用途的线长汇总。
- 在只读 STA / slack 批次内缓存时序开关，批次外保留同对象动态切换行为。
- 复用相同 SLL 路径输入段的延迟计算；坐标变化或不满足缓存条件时使用原计算路径，保持浮点算术顺序及 L 各项含义。
- Slack 扫描使用现有线程数并行处理独立 net，以线程内整数直方图和原 net 顺序写回保证确定性。
- 复用规划收集缓冲区，补充 collect/rebuild/criticality/index 等 profile；不减少规划刷新、STA 或 QP 次数。

## GETRF 单次同机对照

共同条件：eda072、U250、10 ns、AMF 12 线程、普通 Pro / ProPrimitiveTiming=false、完整 SLL 优化开启、visualization=false、CrossDieSpreadMaxBins=0。复用综合与网表导出，只执行 AMF 布局及计划导出。

|范围|优化前 / s|提速版 / s|
|---|---:|---:|
|AMF 进程墙钟|1354.700|1291.309|
|Slack 阈值扫描|56.583|11.051|
|STA 完整调用窗口|219.116|205.044|
|SLL 规划刷新|80.116|76.961|

总墙钟减少 **63.391 s（4.68%）**。函数窗口不能与总墙钟相加。单次串行对照不代表统计稳定均值；并行 slack 扫描也加速普通连线，不能把全部收益归为 SLL 特有开销。

## 功能与输出核验

- 37 轮全局布局、92 次 QP、307 次规划刷新、214 次 STA 和 49 次 slack 扫描保持。
- 最终布局 Tcl、资源/级联表、FinalLUTFF 解压内容、SLL 计划字节一致。
- PUInfoFinal 的无序 PULegalization 记录仅输出顺序不同；121165 条记录排序后内容一致，其余解压字节一致。
- 9446 条跨 die net / 9467 条 crossing 保持，边界 0–1 为 8974、1–2 为 493；最拥挤规划列为 75%，无 tile 超容量。
- 延迟前缀位级比较、原动态功能开关测试、1/12 线程 slack 等价测试、真实 U250 集成测试通过。
- 未执行新 Vivado 布线，不宣称新 WNS、可布线性或端到端编译加速。

## 参数与范围

本版继承现有 CrossDieSpreadMaxBins 可选限幅及 fractional-Y bin 写回修正；常用配置缺省 20，设为 0 关闭新整轮限幅。本次提速对照两组均显式设为 0，4.68% 结果不代表 20-bin 限幅带来的收益。其他既有参数和默认值保持源码原样。

本版没有实现后续讨论的密度网格重建、通用边界报告或扩散数据结构加速。这些仍为后续候选方向。实验 DCP、二进制、大型数据和完整运行日志不进入本次提交。
